# 쓰다보면

장유중앙교회 성경필사 모임 **쓰다보면**의 앱입니다. 오늘 쓸 분량을 확인하고, 다 쓰면 체크하고, 사진으로 인증하면
진행률·남은 분량·순위·인증방이 함께 보입니다. "뛰다보면"과 같은 구조입니다.

| 구성 | 위치 |
|---|---|
| 앱 화면 | 이 저장소 (`index.html` 등) → GitHub Pages 로 공개 |
| 데이터 | 구글 드라이브의 시트 **쓰다보면** (`members`, `plan`, `checks` …) |
| 서버 | 시트에 붙인 앱스 스크립트 (`apps-script/Code.gs`) |
| 인증 사진 | 드라이브의 **쓰다보면 인증사진** 폴더 (최근 90일만 보관) |

## 처음 한 번만 하는 설치

### 1. 서버 코드 붙이기
1. 구글 시트 **쓰다보면**을 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣습니다. 저장(💾).
4. 위쪽 함수 선택 칸에서 **setup** 을 고르고 **실행**을 누릅니다. 권한 승인 창이 뜨면 본인 계정으로 허용합니다.
   (고급 → 안전하지 않은 페이지로 이동 → 허용. 본인이 만든 스크립트라서 나오는 안내입니다.)
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포를 누르면 `https://script.google.com/macros/s/…/exec` 주소가 나옵니다. 복사해 둡니다.

### 2. 앱에 서버 주소 넣기
`config.js` 의 `API_URL` 따옴표 안에 위 주소를 붙여 넣고 저장(커밋)합니다.

### 3. 앱 공개하기 (GitHub Pages)
저장소 **Settings → Pages → Branch: main / (root) → Save**.
몇 분 뒤 `https://jangyu-church.github.io/pilsa/` 주소가 생깁니다. 이 주소를 단톡방에 공유하면 됩니다.
폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

### 4. 관리자 정하기
시트의 `admins` 탭 A열에 관리자 **이름**을 한 줄씩 적습니다(처음에는 `이경로` 가 적혀 있어요).
> 주의: 이름이 같은 사람이 먼저 등록하면 그 사람이 관리자가 됩니다. **관리자 본인이 가장 먼저 등록한 뒤** 주소를 공유하세요.

## 서버 코드를 새로 붙였을 때 (기능이 추가될 때마다)
`apps-script/Code.gs` 가 바뀌면 시트의 Apps Script 에 **전체를 다시 붙여넣고** 아래 순서로 새 버전을 배포해야 새 기능이 켜집니다.
1. 저장(💾) → 함수 목록에서 `setup` 선택 → **실행** (이미 한 적이 있어도 한 번 더 눌러도 안전해요. 새 탭 `staff`, `cheers`를 만들어 줘요.)
2. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포** (주소는 그대로예요.)

## 사용법
- **역할은 3단계예요.**
  | 역할 | 할 수 있는 일 | 정하는 사람 |
  |---|---|---|
  | **최고 관리자** | 모든 일. 시트 `admins` 탭에 이름이 적힌 분(처음엔 `이경로`) | 시트에서 직접 |
  | **관리자** (최대 5명) | *관리* 탭 전체: 일정 올리기, 공지, 운영진 지정, 참여자 비밀번호 다시 정하기·내보내기 | 최고 관리자만 |
  | **운영진** (최대 3명) | 앱 오른쪽 위 ⚙ *설정*에서 **공지** 올리기·내리기 | 관리자·최고 관리자 |
  | 회원 | 필사 체크, 인증, 응원 | |
- 역할은 *관리* 탭의 참여자 목록에서 이름 옆 선택 칸으로 바꿔요. **관리자 계정(최고 관리자 포함)의 비밀번호 변경·내보내기·역할 변경은 최고 관리자만** 할 수 있어요. 지정된 관리자가 최고 관리자 계정을 건드릴 수 없게 막혀 있어요.
- 올린 공지는 모두의 화면 위쪽에 보이고, 이름 옆에 **관리자/운영진** 표시가 붙어요.
- **응원**: *인증방*에서 각자의 인증 아래 ‘응원’ 버튼을 누르면 상대 화면에 ‘응원이 도착했어요’가 떠요. *현황* 순위에서도 오늘 일정으로 응원을 보낼 수 있어요. 응원은 최근 7일 것만 앱에 보여요.
- **홈 화면 설치**: 앱을 처음 열면 아래쪽에 ‘앱으로 설치해 보세요’ 안내가 나오고, 놓친 분은 ⚙ *설정 → 홈 화면에 앱 설치*에서 할 수 있어요. 카카오톡 안에서 열면 ‘다른 브라우저로 열기’를 먼저 안내해요.
- **회원**: 처음 한 번 이름과 숫자 4자리 비밀번호를 등록하면, 그 폰에서는 다시 묻지 않습니다.
- **PDF로 일정 올리기**: *관리* 탭 맨 위에서 PDF나 텍스트 파일을 고르면 날짜와 성경 범위가 있는 줄을 읽어 일정으로 만들어 줍니다. 글자가 들어 있는 PDF만 읽을 수 있고, 사진이나 스캔본은 읽지 못합니다. 읽은 뒤 꼭 미리보기를 확인하세요. (PDF 읽기는 `vendor/` 폴더의 pdf.js 를 사용합니다.)
- **사진·스캔 일정표**: 앱은 글자를 못 읽으니, 사진을 먼저 Claude 같은 AI에게 주고 "날짜 | 범위 | 장수 표로 만들어 줘"라고 한 뒤, 나온 표를 *관리* 탭의 일정 칸에 그대로 붙여넣으세요. 표 모양(`| 날짜 | 범위 |`)도 읽습니다.
- **분량 단위(장/회)**: *관리* 탭 3번 칸의 ‘하루 분량을 세는 단위’에서 정해요. 성경 장 수로 세면 **장**, 서신서처럼 ‘하루 한 번’으로 세면 **회**예요. 일정 줄의 세 번째 숫자가 하루 분량이에요.
- **밀린 날 한 번에 체크**: 모임 중간에 앱을 쓰기 시작한 분은 *오늘* 탭의 ‘밀린 N일 모두 썼어요’를 두 번 눌러 한꺼번에 체크할 수 있어요. (사진 없이 완료로 기록돼요.)
- `seasons/` 폴더에는 지난 시즌 일정 줄이 보관돼 있어요. 관리 탭에 그대로 붙여넣어 다시 올릴 수 있어요.
- 일정 줄 형식: `2026-11-02 | 요한복음 1-3장 | 3` (날짜 | 범위 | 장 수). 장 수를 비우면 책 이름에서 계산합니다.

## 코드를 고친 뒤
- 화면(`index.html`, `config.js` …)을 고치면 GitHub 에 올리기만 하면 됩니다.
- `Code.gs` 를 고쳤다면 Apps Script 에서 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. 주소는 그대로예요.

## 알아 둘 점
- 비밀번호는 4자리 숫자라 보안 용도가 아니라 **다른 사람이 내 이름으로 체크하는 것을 막는 정도**입니다. 5번 틀리면 10분간 잠깁니다.
- 인증 사진은 작게 줄여 저장하며 최근 90일(약 3개월) 것만 남깁니다. 그보다 오래된 사진은 그 사람이 새 사진을 올릴 때 드라이브 휴지통으로 옮겨져요. 체크 기록은 그대로 남아요. 사진 주소를 아는 사람은 볼 수 있으니 민감한 사진은 올리지 마세요.
- 구글 앱스 스크립트는 하루 사용량 한도가 있지만 소규모 모임에서는 충분합니다.
